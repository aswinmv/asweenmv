# Aswin MV — Portfolio Website

Portfolio of **Aswin MV**, Social Media & Influencer Marketing Specialist at Fulva by Calicut Cousins, based in Kerala, India.

Live site: https://aswinmv.in

## Features
- Minimal, modern, responsive single-page portfolio
- Multi-language support (English, Spanish, French, German, Portuguese, Japanese, Chinese)
- SEO-optimized: structured data, Open Graph, Twitter Cards, image sitemap, web manifest
- Accessible: skip-to-content, ARIA labels, keyboard navigation
- Fast: lazy-loaded sections, deferred analytics, async font loading

## Tech Stack
- React 18 + TypeScript
- Vite 7
- Tailwind CSS 3
- Lucide React icons

## SEO Setup
- `robots.txt` — allows all search engines, blocks AI training crawlers
- `sitemap.xml` — includes image sitemap data
- `site.webmanifest` — PWA manifest for installability
- Structured data: Person, WebSite, and Occupation schema.org types
- Noscript fallback content for non-JavaScript crawlers and users
- Open Graph + Twitter Card meta tags for rich social sharing previews
